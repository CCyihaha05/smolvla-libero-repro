# 失败行为归因（11 对配对视频）

> 对 50 对「同初始状态、N=10 成功 / N=50 失败」的配对视频中的 **11 对**做逐对观看与分类。  
> 在线播放器：[`failure_analysis/index.html`](../failure_analysis/index.html)

---

## 1. 方法

- **素材**：同一 task、同一 episode 编号在不同 `n_action_steps` 下的 rollout。LIBERO 使用固定初始状态，因此两侧是**完全相同的初始条件**，唯一变量是 `n_action_steps`。
- **观察三项**：① N=10 的成功轨迹；② N=50 第一次偏离的时刻；③ 偏离后机械臂的行为。
- **分类体系**：

| 标签 | 判据 |
|---|---|
| 定位偏差 | 夹爪闭合时没对准物体 |
| 抓取滑脱 | 抓住了但抬起/移动中掉落 |
| 碰撞干扰 | 撞到其他物体并改变场景 |
| 动作滞后 | 已明显偏离目标，仍继续执行旧方向的动作 |
| 步数耗尽 | 动作方向正确但 280 步内未完成 |
| 无有效动作 | 几乎不动或原地抖动 |

## 3. 分布

| 类型 | 涉及次数 | 占比 |
|---|---|---|
| **定位偏差** | **9 / 11** | **82%** |
| **动作滞后** | **6 / 11** | **55%** |
| 抓取滑脱 | 1 / 11 | 9% |

> 复合标签（定位偏差 + 动作滞后）占多数，说明二者在实际失效中是**耦合**的：定位偏差是触发因素，动作滞后是放大器。

---

## 4. 核心发现：机制不是"误差累积"，而是"失去重试窗口"

### 观察 1：N=10 的成功轨迹本身就包含失败重试

11 个成功样本中，至少 **4 个**（#2、#3、#4、#5）经历了：

```
抓取失败 → 重新观测 → 重试 → 成功
```

其中 #5 甚至需要**侧移重新对准**才能成功。

**这说明策略的单步定位精度本来就不完美**，它的鲁棒性来自闭环重试。

### 观察 2：N=50 的失败模式是"一次失误后无法重试"

| 行为 | 样本 | 含义 |
|---|---|---|
| 抓空后直接移向篮子 | #1、#10 | 它"以为"已经抓到了，继续执行后续动作 |
| 同一位置反复抓取 | #2、#4、#6、#7、#9、#11 | 重新观测了，但位置没变，仍然抓空 |
| 抓错物体 | #8（篮子）、#10（另一个罐子） | 动作方向对，目标定位失准 |
| 打滑 | #3 | 唯一一个真正"抓到但掉了"的样本 |

### 修正后的机制

> N=10 与 N=50 的**单步定位精度没有本质差异**——两者的第一次抓取都有相当比例是失准的。
>
> 差别在于：N=10 每 10 步重新观测一次，**一次抓空后能在下一个窗口立刻重试并成功**；N=50 在抓空后还要继续执行几十步已经失效的计划，要么带着空夹爪完成后续动作，要么在错误位置反复重试。
>
> **开环执行的核心代价不是"精度下降"，而是"剥夺了从错误中恢复的机会"。**

## 5. 局限

- 只分析了 **11 / 50 对**，且集中在 bbq sauce / alphabet soup / butter 三类物体
- 存在复合标签，说明分类体系需要更细的二级标签
- 未做定量标注（如偏离时刻的精确帧号），属于定性分析
- 未与 MuJoCo 接触力数据做交叉验证（可作为后续工作）
